# 🐘 유토리와 뱅토리의 두근두근 치앙마이 여행

2026.08.30 – 09.06 · 7박 8일 · 부산(PUS) ⇄ 치앙마이(CNX)

여행 일정·지도·이동수단을 한 화면에서 관리하는 모바일 우선 웹앱입니다.
빌드 도구 없이 정적 파일만으로 동작하며 GitHub Pages에 배포됩니다.

## 기능

| | |
|---|---|
| 🔒 **잠금** | 4자리 PIN 화면 잠금 (SHA-256 비교, 순수 JS) |
| 🌏 **히어로** | 부산 → 치앙마이 대권항로 지구본 애니메이션 (Canvas · 정사도법) |
| 🗓 **일정** | D0~D7 날짜별 타임라인, 카테고리·필수·예약 뱃지, 예상 비용 |
| 🚕 **이동수단** | 일정 사이 거리·소요시간·요금 자동 추정 (Grab / 썽태우 / 툭툭 / 도보 / 투어차량) + 구글맵 길찾기 |
| 🗺 **지도** | 영문 라벨 핀 지도(한글 이름표) ↔ 한글 구글맵 전환, 날짜별 동선 표시 |
| ➕ **편집** | 일정 추가·수정·삭제 → 스케줄과 지도에 즉시 반영, localStorage 저장 |
| 🔗 **공유** | 변경사항을 URL에 담아 공유 (상대 기기에도 그대로 반영) |
| ℹ️ **정보** | 항공편·숙소·예산·준비물 체크리스트·현지 팁 |
| 💻 **반응형** | 모바일 단일 컬럼 / 데스크톱 2분할(일정 + 고정 지도) |

## 구조

```
index.html
assets/
├─ css/style.css      디자인 시스템 (라이트·다크)
└─ js/
   ├─ data.js         여행 데이터 (일정·항공·예산·준비물·팁)
   ├─ transit.js      이동수단 추천 · 요금/시간 추정
   ├─ globe.js        히어로 지구본 (해안선 데이터 내장)
   ├─ store.js        상태 저장 (시드 + 변경분 delta)
   ├─ mapview.js      Leaflet 지도 · 구글맵 임베드
   └─ app.js          UI 렌더링 · 이벤트
```

일정 기본값은 `assets/js/data.js`의 `items` 배열에 있습니다.
앱에서 수정한 내용은 원본을 건드리지 않고 **변경분(delta)** 으로만 저장되므로,
`data.js`를 업데이트해도 내가 추가한 일정은 유지됩니다.

## 로컬 실행

```bash
python3 -m http.server 8899
```

## 참고

- 교통비·소요시간은 직선거리 기반 **추정치**입니다. 실제 요금은 시간대·교통상황에 따라 달라집니다.
- PIN은 **화면 잠금 수준**의 보호입니다. 정적 호스팅 특성상 소스를 열면 내용을 볼 수 있습니다.
- 지도 타일: Esri World Street Map · 장소 검색: Nominatim(OpenStreetMap) · 경로 안내: Google Maps
