# 🐘 유토리와 뱅토리의 두근두근 치앙마이 여행

2026.08.30 – 09.06 · 7박 8일 · 부산(PUS) ⇄ 치앙마이(CNX)
숙소: 님만해민 로드 소이 6 (Airbnb · 체크아웃 9/7 11:00)

여행 일정·지도·이동수단을 한 화면에서 관리하는 모바일 우선 웹앱입니다.
빌드 도구 없이 정적 파일만으로 동작하며 GitHub Pages에 배포됩니다.

## 기능

| | |
|---|---|
| 🔒 **잠금** | 4자리 PIN 화면 잠금 (SHA-256 비교, 순수 JS) |
| 🌏 **히어로** | 부산 → 치앙마이 대권항로 지구본 애니메이션 (Canvas · 정사도법) |
| 🗓 **일정** | D0~D7 날짜별 타임라인, 카테고리·필수·예약 뱃지, 예상 비용 |
| 📅 **달력** | 8일 × 시간 그리드로 전체 일정 한눈에. 빈 칸을 누르면 그 시간으로 추가. **블록을 꾹 눌러 끌면 시간·날짜 이동**, **위아래 끝을 잡아 끌면 길이 조절**(5분 단위) |
| 📍 **추천** | 야시장·카페·술집·식당·액티비티·사원·스파 45곳. 카드/지도 전환, 카테고리별 색상 핀. 골라서 날짜·시간 지정 후 일정에 추가 |
| 🚕 **이동수단** | 일정 사이 거리·소요시간·요금 자동 추정 (Grab / 썽태우 / 툭툭 / 도보 / 투어차량) + 구글맵 길찾기 |
| 🗺 **지도** | 날짜 아래·스케줄 위에 인라인 표시. 영문 라벨 핀 지도(한글 이름표) ↔ 한글 구글맵 전환, 핀 탭 시 해당 카드로 이동 |
| ➕ **편집** | 일정 추가·수정·삭제 → 스케줄과 지도에 즉시 반영, localStorage 저장 |
| 🔗 **공유** | 변경사항을 URL에 담아 공유 (상대 기기에도 그대로 반영) |
| ℹ️ **정보** | 항공편·숙소·예산·준비물 체크리스트·현지 팁 |
| 💻 **반응형** | 모바일: 일정 안에 지도 인라인 / 데스크톱: 2분할(일정 + 오른쪽 고정 지도) |

## 구조

```
index.html
assets/
├─ img/               추천 카드 사진 19장 (Wikimedia Commons, CC)
├─ css/style.css      디자인 시스템 (라이트·다크)
└─ js/
   ├─ data.js         여행 데이터 (일정·항공·예산·준비물·팁)
   ├─ places.js       추천 장소 45곳 (카테고리·영업시간·설명·팁·사진)
   ├─ transit.js      이동수단 추천 · 요금/시간 추정
   ├─ globe.js        히어로 지구본 (해안선 데이터 내장)
   ├─ store.js        상태 저장 (시드 + 변경분 delta)
   ├─ mapview.js      Leaflet 지도 · 구글맵 임베드
   └─ app.js          UI 렌더링 · 이벤트
```

기본 데이터에는 **확정된 예약(항공 2편·숙소·ATV 투어) + 하고 싶은 것 기반으로 짠 D1~D7 동선**이 들어있습니다.
일정 기본값은 `assets/js/data.js`의 `items` 배열에 있습니다.

- 하루 중 **일부러 비워둔 시간대**가 있습니다 (D1 14~16시 / D2 13:30~16:30 / D4 09~16시 호텔 / D5 저녁 / D6 13~16:30 / D7 15~17시).
  가고 싶은 곳을 찾으면 「추천」 탭이나 달력 뷰 빈 칸에서 바로 꽂아 넣으세요.
- **「이 부근에서 골라서」** 라고 적힌 칸(산티탐 카페 투어·핑강변 카페·각 끼니)은 특정 가게를 정하지 않고 동네만 지정한 항목입니다.
  지도 핀은 그 동네 중심점이에요.
앱에서 수정한 내용은 원본을 건드리지 않고 **변경분(delta)** 으로만 저장되므로,
`data.js`를 업데이트해도 내가 추가한 일정은 유지됩니다.

## 배포

```bash
sh bump.sh && git add -A && git commit -m "..." && git push
```

`bump.sh`는 `index.html`의 asset 쿼리(`?v=N`)를 올려 브라우저 캐시를 무효화합니다.
GitHub Pages가 `max-age=600`이라 이걸 건너뛰면 배포 직후 접속한 사람이
새 HTML + 옛 JS 조합을 받아 기능이 동작하지 않을 수 있습니다.
